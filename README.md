# IO-Analysis-PLUS: 2023년 산업연관표 분석 웹앱

한국은행 **2023년 산업연관표(연장표)** 의 투입산출표를 브라우저에서 탐색하고, 수요충격 시뮬레이션과 산업 구조 분석(유발계수·전후방 연쇄효과)을 수행하는 웹앱입니다. GitHub Pages에서 동작하며, 별도의 서버 없이 방문자의 브라우저에서 Pyodide(WebAssembly 기반 Python)로 계산합니다.

## 이 앱의 목적

> 수출과 내수(소비·투자) 수요가 늘 때 **국내에 부가가치가 얼마나 남고, 해외로 수입이 얼마나 새어 나가는지**, 그리고 어떤 제품의 수입이 늘어나는지를 확인합니다. 같은 분석을 대·중·소분류와 기본부문에서 돌려 분류 수준에 따라 결과가 어떻게 달라지는지도 비교합니다.

본 프로젝트는 수업에서 제공된 예시 코드(profguclass/Sample_IO)를 바탕으로, 네 가지 분류 지원, 수요 항목별 분석, 산업 구조 분석 기능을 추가해 확장했습니다. 개발에는 AI 코딩 도구의 도움을 받았습니다.

## 사용 방법

1. 페이지 상단 **분류 선택**에서 대분류 / 중분류 / 소분류 / 기본부문 중 하나를 고르고 **불러오기**를 누릅니다. 처음에는 Python 실행 환경을 준비하느라 수십 초 걸릴 수 있습니다. 한 번 준비되면 다른 분류로 바꿀 때는 더 빠릅니다.
2. **원자료 탐색**: 시트(12개)와 행을 고르면 해당 행이 각 열과 어떻게 연결되는지 표로 보여줍니다. 행·열 이름 또는 코드로 검색할 수 있습니다.
3. **시뮬레이터**: 산업을 검색해 선택하고 최종수요 증가액(백만원)을 입력한 뒤 시나리오에 추가합니다. 여러 산업을 추가하면 합산하여 **파급효과 계산**을 실행합니다. 결과는 CSV로 내려받을 수 있습니다.
4. **수요 항목별 분석**: 민간소비, 정부소비, 투자, 재고, 수출 등 최종수요 항목마다 국산 최종수요 1원이 부가가치로 남는 몫과 수입 중간재로 새는 몫을 막대 차트와 표로 비교합니다. 항목을 선택하면 그 수요가 유발하는 생산·수입·부가가치를 산업별로 보여주고, 수입이 많이 늘어나는 상위 15개 산업(제품)을 막대로 표시합니다. 차트는 PNG, 표는 CSV로 저장할 수 있어 보고서에 바로 쓸 수 있습니다.
5. **산업 구조 분석**: 산업별 생산·수입·부가가치유발계수, 영향력계수, 감응도계수와 연쇄효과 유형을 표로 보여줍니다. 유형 필터, 검색, 정렬, CSV 다운로드를 지원합니다.

## 단위

| 항목 | 단위 |
|---|---|

| 투입계수, 유발계수, 영향력계수, 감응도계수 | 단위 없는 비율 (원/원) |
| 생산유발승수 | 배 (생산유발액 ÷ 최종수요 증가액) |
| 수요 항목별 계수(생산·수입 중간재·부가가치) | 국산 최종수요 1원당 원 |

## 분석 방법

- 수요충격: 최종수요 증가 벡터 *f*에 대해 생산유발액 = *L f*, 수입유발액 = *M f*, 부가가치유발액 = *V f*. *L*, *M*, *V*는 원표의 생산·수입·부가가치유발계수 행렬입니다. 최종수요 증가는 국내 생산물에 대한 수요만 입력하며(수입 완제품 구매 제외), 현재는 양(+)의 증가만 지원합니다.
- 유발계수(산업별): 생산유발계수표의 열합(해당 산업 최종수요 1원 증가 시 전 산업의 생산 유발액). 수입·부가가치유발계수도 같은 방식입니다.
- 수요 항목별 분석: 원자료의 '최종수요 항목별 생산·수입·부가가치유발액' 시트와 국산·수입거래표의 최종수요 열을 사용합니다. 정의는 다음과 같으며, 앱에서 계산한 결과는 모든 분류·모든 항목에서 부가가치유발계수와 수입(중간재)유발계수의 합이 1임을 확인했습니다.
  - 생산유발계수 = 생산유발액 ÷ 국산 최종수요, 부가가치유발계수 = 부가가치유발액 ÷ 국산 최종수요
  - 수입(중간재)유발계수 = (수입유발액 − 수입 최종재) ÷ 국산 최종수요. 국산 최종수요 1원은 국내 부가가치 또는 수입 중간재로 귀결되므로 부가가치유발계수와 더하면 1입니다.
  - 공표 수입유발계수 = 수입유발액 ÷ (국산 + 수입 최종수요). 한국은행 표에 실린 값으로, 소비·투자가 직접 구매한 수입 완제품을 포함하므로 위 중간재 계수와 값이 다릅니다. 두 계수의 정의가 달라 항목 간 비교에는 중간재 계수를 쓰는 것이 적절합니다.
- 영향력계수(후방연쇄효과): 열합 ÷ 열합의 전체 평균. 1보다 크면 다른 산업에 미치는 파급력이 평균 이상입니다.
- 감응도계수(전방연쇄효과): 행합 ÷ 행합의 전체 평균. 1보다 크면 다른 산업의 수요 증가에 평균 이상 반응합니다.
- 연쇄효과 유형: 영향력과 감응도가 각각 1 이상인지에 따라 네 가지(전·후방 모두 강함, 후방 강함, 전방 강함, 모두 약함)로 구분합니다.
- 계산한 영향력·감응도계수는 원표의 9801행·9802열 값과 일치함을 확인했습니다.

## 계수 검증

자료를 불러올 때마다 다음 관계를 점검하고, 최대 절대 잔차가 1e-8 이상이면 오류로 처리합니다. 화면의 "계수 검증 결과"에서 확인할 수 있습니다.

- (I − Ad) L = I (생산유발계수는 국산투입계수의 레온티에프 역행렬)
- Am L = M (수입유발계수)
- 부가가치계수 ⊙ L = V (부가가치유발계수)
